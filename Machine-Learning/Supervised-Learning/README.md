# Supervised Learning

Etiketli gözlemlerden hedef tahmini öğrenen uygulamalar problem tipine göre ayrılmıştır.

| Alt alan | Hedef türü | Örnek yöntemler |
|---|---|---|
| [Regression](Regression/) | Sürekli sayısal değer | Linear, polynomial, Ridge, Lasso, Elastic Net |
| [Classification](Classification/) | Kategori veya sınıf | Logistic Regression, SVM, Decision Tree, Random Forest, boosting |
| [Mixed Tasks](Mixed-Tasks/) | Aynı veri üzerinde farklı hedef türleri | Random Forest regresyon ve sınıflandırma |

Değerlendirmede regresyon için MAE, RMSE ve R²; sınıflandırma için precision, recall, F1 ve ROC-AUC kullanılır.
