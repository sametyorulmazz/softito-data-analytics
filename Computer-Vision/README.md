# Computer Vision

Piksel düzeyindeki temel işlemlerden renk tabanlı nesne tespitine ve derin öğrenme mimarilerine ilerleyen görüntü işleme koleksiyonu.

| Bölüm | İçerik |
|---|---|
| [Fundamentals](Fundamentals/) | Görüntü oluşturma, dönüşüm, filtre, kenar, eşikleme ve kontur |
| [Classical Computer Vision](Classical-Computer-Vision/) | BGR/RGB, HSV, LAB, YCrCb ve renk maskeleri |
| [Deep Learning](Deep-Learning/) | CNN, MobileNetV2 ve YOLO iş akışları |

OpenCV projeleri yerel sentetik görüntülerle doğrudan çalışır. CIFAR-10 kullanan CNN uygulaması veri setini ilk çalıştırmada indirir.
