# Programming Fundamentals

Veri analitiği uygulamalarında kullanılan Python programlama ve veri işleme yapılarını kademeli olarak ele alan temel çalışmalar.

| Bölüm | Kapsam |
|---|---|
| [Python](Python/) | Değişkenler, koleksiyonlar, kontrol akışı, fonksiyonlar ve sınıflar |
| [NumPy](NumPy/) | Diziler, vektörleştirme, indeksleme, yayınlama ve dosya işlemleri |
| [Pandas](Pandas/) | DataFrame işlemleri, veri okuma ve temizleme |

Bu bölümde görsel raporlama yerine kısa, çalıştırılabilir kod örnekleri ve terminal çıktıları önceliklidir.
