# Python Fonksiyonları ve Sınıfları

Tekrar kullanılabilir fonksiyonlar ile nesne yönelimli programlama yapılarını veri odaklı küçük uygulamalar üzerinde birleştirir.

## Kapsam

- Parametre, varsayılan değer ve dönüş değeri
- Veri sınıfı ve kapsülleme
- Kalıtım ve soyut sınıflar
- Birbiriyle çalışan sınıflardan küçük bir kütüphane sistemi

Harici veri seti veya üçüncü taraf bağımlılık kullanılmaz.

## Çalıştırma

```bash
python fonksiyonlar_ve_siniflar.py
```
