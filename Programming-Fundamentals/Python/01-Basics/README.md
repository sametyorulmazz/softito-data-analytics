# Python Temelleri

Veri analitiği kodlarının temelini oluşturan Python sözdizimini tek çalıştırılabilir dosyada toplar.

## Kapsam

- Değişkenler, temel veri tipleri ve metin işlemleri
- Liste, tuple, sözlük ve küme yapıları
- Koşullar, döngüler ve comprehension kullanımı
- `try/except` ile hata yönetimi
- Dosya okuma ve yazma

Örnekler veriyi kod içinde oluşturur; harici veri seti gerekmez.

## Çalıştırma

```bash
python python_temelleri.py
```
