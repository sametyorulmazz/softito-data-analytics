# İleri Düzey NumPy

Performans, bellek yönetimi ve bilimsel hesaplama için kullanılan ileri NumPy araçlarını uygulamalı olarak inceler.

## Kapsam

- Bellek düzeni, strides, C-order ve F-order
- Gelişmiş broadcasting ve kayan pencere işlemleri
- `einsum`, maskeli diziler ve modern `Generator` API
- FFT, polinom uydurma ve tarih/zaman dizileri
- `argpartition`, `apply_along_axis` ve `memmap`

Veriler kod içinde sabit tohumla oluşturulur; çalışma sonunda geçici büyük dizi dosyası kontrollü biçimde kapatılır.

## Çalıştırma

```bash
pip install -r requirements.txt
python numpy_ileri_duzey.py
```
