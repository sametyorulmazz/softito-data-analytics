# NumPy Temelleri

Sayısal analizin temel veri yapısı olan `ndarray` üzerinde dizi oluşturma, seçme, dönüştürme ve hesaplama işlemlerini gösterir.

## Kapsam

- Tek ve çok boyutlu dizi oluşturma
- Boyut, şekil ve veri tipi inceleme
- İndeksleme, dilimleme ve reshape
- Vektörleştirilmiş matematik ve broadcasting
- Toplulaştırma, rastgele sayı üretimi ve doğrusal cebir

Tüm diziler kod içinde üretilir.

## Çalıştırma

```bash
pip install -r requirements.txt
python numpy_temelleri.py
```
