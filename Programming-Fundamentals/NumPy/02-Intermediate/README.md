# Orta Düzey NumPy

NumPy dizilerinde bellek davranışı, gelişmiş indeksleme, vektörleştirme ve dosya saklama işlemlerini ele alır.

## Kapsam

- View ve copy farkı
- Fancy indexing, boolean maskeleme ve `np.where`
- Sıralama, birleştirme, bölme ve eksen kullanımı
- Döngü ile vektörleştirme performans karşılaştırması
- Ufunc, structured array ve doğrusal denklem çözümü
- NPY ve NPZ formatlarında veri kaydetme/yükleme

`data/ornek_array.npy` ve `data/coklu_array.npz`, dosya işlemleri bölümünün yeniden kullanılabilir çıktılarıdır.

## Çalıştırma

```bash
pip install -r requirements.txt
python numpy_orta_duzey.py
```
